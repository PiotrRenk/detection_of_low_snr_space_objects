# Detection_of_low_snr_space_debris
The goal of this project is to analyze different methods to detect low snr objects in all kinds of different orbits. There are two approaches to this:
1. Do a end-to-end detection without using the stacking of frames (f.e. Unet on a 3D cube)
2. Help synthetic tracking algorithm by narrowing the field of search or by improving the precision by eliminating false positive resoults
